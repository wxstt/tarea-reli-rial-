## 📋 Descripción

Sitio web de una sola página (*single-page*) con estética editorial maximalista que presenta de forma visual e interactiva el contenido completo del trabajo extraclase de Educación Religiosa. Incluye:

- **Marco conceptual** — preguntas generadoras y lema del proyecto.
- **Definiciones** — fe como confianza existencial y razón como método empírico.
- **Tríada epistemológica** — conocimiento científico, filosófico y religioso con tabla comparativa.
- **Análisis dialéctico** — los dos extremos nocivos: fanatismo vs. cientificismo radical.
- **Aportes mutuos** — qué le da la razón a la fe y la fe a la razón.
- **Dossier histórico** — cinco figuras científicas y creyentes: Tomás de Aquino, Galileo, Mendel, Lemaître y Francis Collins.
- **Caso contemporáneo** — Inteligencia Artificial, bioética y dignidad humana (UNESCO 2021).
- **Sección «Mi pensamiento»** — las 7 preguntas reflexivas con respuestas textuales.
- **Síntesis final** — «¿Qué aprendí y qué cambió en mi manera de pensar?».
- **Referencias APA 7** — corpus bibliográfico completo.

## 🚀 Publicar en GitHub Pages

### Paso a paso rápido

1. Crea un repositorio en [github.com](https://github.com) (puede ser público o privado con Pages habilitado).
2. Sube todos los archivos de esta carpeta a la **raíz** del repositorio:
   ```bash
   git init
   git add .
   git commit -m "Sitio Fe y Razón — versión inicial"
   git branch -M main
   git remote add origin https://github.com/TU-USUARIO/TU-REPOSITORIO.git
   git push -u origin main
   ```
3. En tu repositorio ve a **Settings → Pages**.
4. En *Source*, elige **Deploy from a branch → `main` → `/` (root)**.
5. Guarda. En 1–2 minutos el sitio estará disponible en:
   ```
   https://TU-USUARIO.github.io/TU-REPOSITORIO/
   ```

> **No necesitas Jekyll, Node.js ni ningún build step.** Es HTML + CSS + JS puro, funciona directamente desde cualquier servidor estático.

## 🎨 Diseño

Estética **editorial maximalista** inspirada en revistas académicas de vanguardia, dossieres de archivo y gacetas históricas:

- **Paleta cromática:** papel de archivo envejecido · tinta china · lacre bermellón · oro antiguo · verde musgo
- **Tipografía:** *Cormorant Garamond* (titulares serif elegantes) + *Jost* (cuerpo limpio) + *DM Mono* (datos y etiquetas)
- **Detalles ornamentales:** textura de cuaderno de registro · sombras brutalistas · ticker de noticias · fichero bibliográfico · numeración romana en fichas históricas · ornamentos tipográficos de fondo
